GSOP brand fonts (self-hosted)

Included here as WOFF2 (Latin subset only):
  Space Grotesk 500 / 600 / 700   — logo, headings, display
  Inter 400 / 500 / 600           — body copy
  JetBrains Mono 400 / 500        — technical labels, descriptor line

All three families are licensed under the SIL Open Font License 1.1; the licence text for each is in this folder (ofl-*.txt).
Source: Fontsource packages (@fontsource/space-grotesk, @fontsource/inter, @fontsource/jetbrains-mono).
Only the weights listed above are included. Characters outside the Latin subset fall back to the system stack defined in brand-tokens.css.
Logo and wordmark artwork do not depend on these files — their lettering is converted to vector outlines.
