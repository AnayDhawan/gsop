# Submission text

`template.md` is the text for each field of the submission form, written by hand with placeholders for every number and for the uncertainty sentence.

- `{{claim:ID}}` is replaced with the display string of that row in `public/data/claims.csv`.
- `{{e32}}` is replaced with `docs/E32.txt`, word for word.
- `{{india_region}}` and `{{india_tiles}}` name the one listed region that overlaps the India outline and its tile count. If the number of such regions stops being one, the build stops so the sentence gets rewritten.
- `SUBMISSION.md` is generated by `python3 scripts/build_submission.py`. Do not edit it by hand.
- `python3 scripts/check_claims.py` checks that the template holds no typed number, that `SUBMISSION.md` matches the template, and that no banned word appears.
